# MiniCraft 3D

Juego inspirado en Minecraft hecho con **Three.js**.

## Cómo ejecutar

Como usa módulos ES y assets desde CDN, sirve el proyecto con un servidor local:

```bash
python3 -m http.server 4173
```

Luego abre en el navegador:

- http://localhost:4173

## Controles

- Menú inicial: click en **Generar mundo nuevo...**
- Click: capturar cursor
- WASD: mover
- Espacio: saltar
- Click izquierdo: destruir bloque
- Click derecho: colocar bloque
- Teclas 1-4: cambiar tipo de bloque
- ESC: liberar cursor
